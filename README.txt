SafeSpend PWA V4.0 · 资金缺口口径修正版

本版修正“现金流仍有缺口”的错误提示。

统一口径：

1. 零花钱可以为负
例如本周期零花钱原本 90 元，已经支出 105 元：
零花钱余额 = -15 元。

2. 零花钱超支先侵蚀“本周期预计可存”
如果本周期原计划可存 200 元：
本周期预计可存 = 200 - 15 = 185 元。

此时仍有 185 元可以存，所以不存在资金缺口。

3. 真正的资金缺口只在：
本周期预计可存 < 0
时出现。

资金缺口 = |本周期预计可存|

例如：
本周期预计可存 = -25 元
才显示：
“本周期资金缺口 ¥25”

4. 删除了每笔日常支出后面容易误导的“尚有缺口 ¥xx”文字。
普通支出只显示金额；整个周期是否真的缺钱，统一由“本周期预计可存”判断。

因此用户截图中的：
收入 500
零花钱初始 90
已经花 105
零花钱余额 -15
本周期预计可存 185

正确结果：
本周期资金缺口 = 0
不应显示“现金流仍有缺口 ¥105”。
