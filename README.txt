SafeSpend PWA V7.9 · 银行转存提醒预计口径版

本版把“银行转存提醒”也改成和储蓄页、结果页一致的预计口径。

现在：

预计日常储蓄 =
已经进入储蓄
+ 当前周期预计结余

银行转存提醒的：
- 当前金额
- 距离提醒额度
- 进度条
- 是否预计达到额度

全部按“预计日常储蓄”计算。

例如：
已经进入储蓄 ¥320
当前周期预计结余 ¥98.74

则转存提醒当前金额按：
¥320 + ¥98.74 = ¥418.74

页面会拆开显示：
- 预计日常储蓄
- 其中已进入储蓄
- 预计周期结余
- 设定转存额度
- 距离提醒额度

安全处理：
预计结余仍然属于零花钱预测值，并没有真正进入储蓄账户。

因此：
1. 如果“预计日常储蓄”达到提醒额度，但实际已进入储蓄还没达到：
   - 提醒会显示“预计达到银行转存额度”
   - 进度条会按预计值达到 100%
   - 暂时不会显示“已存入银行”操作按钮

2. 等实际已进入储蓄也真正达到额度后：
   - 显示“已经达到银行转存额度”
   - 才出现“已存入银行”按钮
   - 银行存款表单只会使用真实可转存的储蓄余额

这样提醒口径与“预计储蓄”完全一致，同时不会把尚未沉淀的零花钱提前当成真的银行存款。
