SafeSpend PWA V8.3 · 自定义日期整合版

保留 V8.2 的设计：
默认只显示一条轻量的“统计范围 · 当前范围 · 调整”。
点击“调整”后才出现折叠选择框。

本版进一步优化展开后的排版：
“自定义日期”不再单独占一整行。

展开后同一行显示：
当前周期 / 本月 / 本年 / 全部 / 自定义

点击“自定义”后，
才在这一行按钮下面展开开始日期和结束日期。

这样：
- 默认页面仍然以收入、消费、预计储蓄增长、储蓄率为视觉重点
- “调整”折叠框继续保留
- 展开后的范围选项只有一整齐的一行
- 不再出现孤零零的一行“自定义日期”

结果计算、日期范围与流水联动逻辑均未改变。
