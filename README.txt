SafeSpend PWA V8.9 · 流水检索版

本版调整两处：

1. “现在 → 最近流水”提示文字简化为：
只显示最近8条

最近流水的实际逻辑不变：
仍然是全部流水中按日期排序后的最近 8 条。

2. “结果 → 流水记录”增加检索

搜索框：
搜索金额 / 项目 / 备注

检索只作用于当前结果页已经选择的时间范围，
不会改变上方收入、消费、预计储蓄增长和储蓄率的统计口径。

可检索内容包括：
- 金额，例如 620、98.74
- 专项名称
- 固定账单名称
- 收入计划名称
- 单次收入备注
- 支出备注
- 流水类别，例如“专项”“固定账单”“储蓄”“基础生活”
- 日期
- 收入分配中的专项名称和金额

支持多个词同时搜索。
例如：
“上海 620”
只会留下同时包含“上海”和“620”的流水。

金额搜索会忽略 ¥ / ￥ 和千位逗号，
因此输入“3500”也可以匹配显示为“¥3,500”的相关流水。

搜索结果仍使用与“最近流水”完全相同的修改 / 删除逻辑。
在检索结果里修改一笔流水后，
余额、专项、储蓄、结果统计以及两个流水列表都会同步重新计算。

没有搜索内容时，流水列表仍按当前范围正常显示；
输入搜索内容后，右上角数量会改成“X 条匹配”。
