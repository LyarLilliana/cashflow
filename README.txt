SafeSpend PWA V10.0 · 多日生活分摊与每日总可花

本版整合：

1. 多日基础生活支出
- 一次录入买菜等覆盖多天的基础生活支出。
- 金额按分精确平均到覆盖日期，总额保持一致。
- 实际付款只记录一次，日常预算按天读取分摊金额。
- 支持在流水中修改或删除，关联日期会自动重新计算。

2. 每日额度分层
- 建议每日零花钱：当前零花余额对应的自由支配建议。
- 建议每日总可花：今日剩余基础生活额度 + 建议每日零花钱。
- 多日生活分摊会自动占用对应日期的基础生活额度。

3. 储蓄页层级调整
- “预计日常储蓄”作为独立总览。
- 下方拆分为“日常储蓄构成”和“银行资产”，减少视觉混淆。

4. 延续 V9.9 / V9.8 修复
- 固定账单当前周期预留同步。
- 同日收入先于当日支出进入资金池。
- 负零花影响本周期预计可存。
- 专项资金按实际已备资金展示，不受预算上限截断。
