SafeSpend PWA V6.5 · 储蓄筛选样式统一版

本版只调整储蓄统计的筛选交互和样式。

储蓄统计现在与“结果 → 流水记录”的筛选样式统一：

第一行：
- 开始日期
- 结束日期

第二行快捷按钮：
- 本月
- 本年
- 全部

第三行显示：
- 当前统计范围
- 对应收入周期数量

手动修改开始日期或结束日期时，会自动进入自定义日期范围。

因此原来的：
“统计范围下拉框 / 指定月份 / 指定年份 / 自定义日期”
不再拆成多组控件，而统一用两个日期输入完成。

功能仍完整覆盖：
- 本月
- 任意月份
- 本年
- 任意年份
- 任意开始/结束日期
- 全部期间

例如：
想看 2027 年 3 月：
开始日期 2027-03-01
结束日期 2027-03-31

想看 2028 年全年：
开始日期 2028-01-01
结束日期 2028-12-31
