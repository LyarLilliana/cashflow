SafeSpend PWA V6.3 · 银行转存提醒版

新增“银行转存提醒”。

一、可以设置转存提醒额度
在储蓄页设置，例如：
¥5,000

提醒口径使用“当前日常储蓄可用”，也就是尚未存入银行的真实普通储蓄余额。

它综合包括：
- 每笔收入中的计划储蓄
- 零花钱主动转储蓄
- 周期结束后剩余零花钱
- 专项结余转储蓄
- 额外储蓄

同时会扣除：
- 已经取用的储蓄
- 专项超支使用的储蓄
- 已经转入银行存款的本金

因此不会把已经存在银行里的钱再算一次。

二、达到额度后提醒
当日常储蓄达到或超过提醒额度：

“现在”页会出现一张提醒卡。
“储蓄”页的银行转存提醒也会进入已达标状态。

都会出现：
“已存入银行”

三、“已存入银行”的流程
点击后打开现有银行存款表单，并自动：
- 本金来源设为“从已有储蓄转入”
- 默认存入金额 = 你设置的提醒额度
- 存入日期 = 今天

之后继续填写：
- 定期 / 活期
- 年利率
- 存期
- 到期处理
- 备注

确认保存后就正式成为一笔银行存款。

四、避免重复计算
从日常储蓄存入银行只是资金位置变化：
日常储蓄减少
银行存款本金增加
总储蓄本金不重复增加

五、支持分笔存款
例如：
提醒额度 ¥5,000
当前日常储蓄 ¥11,000

第一次存 ¥5,000 后还剩 ¥6,000，
因为仍然高于提醒额度，App 会继续保留提醒，
可以再存第二笔。

这样适合把储蓄分批做成多笔定期。
