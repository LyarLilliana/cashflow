SafeSpend PWA V5.3 · 周期储蓄与本周期账单修正版

一、零花钱转储蓄会立即增加“本周期预计可存”

新的口径：
- 计划储蓄：从收入分配时就属于已确定储蓄
- 零花钱：仍然是可花的钱，不会提前计入本周期预计可存
- 主动“零花钱转储蓄”：转多少，本周期预计可存立即增加多少
- 零花钱超支：负数会立即侵蚀本周期预计可存
- 周期结束时：还没花完的正数零花钱自动并入该周期最终储蓄

例：
计划储蓄 200，零花钱 90
当前本周期预计可存 = 200

主动转存 30：
零花钱 = 60
本周期预计可存 = 230

到下一个周期开始时，如果剩余零花钱还有 60：
上一个周期最终可存 = 290

二、额外收入不会另起一个收入周期

“仅一次 / 额外收入”继续属于当前周期：
- 不产生新的基础生活周期
- 不结束当前周期
- 它的储蓄分配和零花钱会并入当前周期
- 只有新的周期性收入到账，才正式结束上一周期

三、“本周期账单”替代“本周期账单预留”

现在卡片表示：
“当前收入周期内，尚未支付的固定账单总额”。

计算范围：
- 从本周期周期性收入到账日开始
- 到下一次周期性收入到账日前结束

已处理 / 无需处理：
- 对应账单会从本周期待支付总额中扣除
- 剩余账单继续显示金额
- 如果本周期所有固定账单都已经关闭，卡片直接显示“已完成”
- 如果本周期本来没有固定账单，显示“暂无”

“近期必须处理”仍然负责逐笔显示固定账单和操作按钮。

四、专项归档、Android 日期修正、专项周期规划等功能保持不变。
