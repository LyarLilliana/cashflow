SafeSpend PWA V4.7 · 固定账单已处理版

新增：
- “近期必须处理”里的固定账单增加“已处理”按钮。
- 点击后直接核销当前缴纳周期。
- 当前周期消失后，同一固定账单立即自动切换到下一缴纳周期。

资金逻辑：
- 如果当前账单周期已经有预留，点击“已处理”会从账单预留核销。
- 如果该周期没有提前预留，点击“已处理”会直接从零花钱支付，避免产生虚假的负账单预留。
- 从零花钱支付时，本周期预计可存会随之降低。
- 删除这条“固定账单已处理”流水后，该缴纳周期会恢复成未处理状态。

列表逻辑：
- 每个固定账单只显示一个当前待处理周期。
- 最近已经到期但尚未处理的账单也会继续显示。
- 处理后自动变成下一个月对应的缴纳周期。
- 专项缺口和本周期资金缺口仍保持原有逻辑，不显示“已处理”按钮，因为它们不是固定周期账单。

其他：
- 表单对齐、日期显示、每日基础生活结算等逻辑保持不变。
