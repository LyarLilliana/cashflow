SafeSpend PWA V7.3 · 结果范围与转存提醒优化版

本版同时调整“结果”和“银行转存提醒”。

结果页：
- 删除“已确认储蓄净增”
- 只保留一个会实时变化的“预计储蓄增长”
- 结果范围支持：当前周期 / 本月 / 本年 / 全部 / 自定义日期
- 当前周期直接跟随真实收入周期，所以每周收入可看一周周期，每月收入可看月度周期
- 结果概览与流水记录共用同一时间范围
- 收入、消费、预计储蓄增长、储蓄率、支出分类与流水全部同步筛选
- 基础生活流水按 coveredDate 归属，与支出统计口径一致

银行转存提醒：
- 首次设置时显示输入框和“保存提醒额度”
- 保存成功后输入框自动折叠
- 保存后只显示当前提醒状态，并出现“修改提醒额度”
- 点击“修改提醒额度”才重新展开输入框
- 达标后的银行转存与存款登记逻辑保持不变
