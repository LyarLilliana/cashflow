SafeSpend PWA V6.4 · 结果与专项明细版

本版重点统一“结果、储蓄、专项”三块的展示和联动。

一、储蓄总览重新命名
顶部：
- 当前储蓄资产 = 日常储蓄余额 + 银行存款本金 + 预估累计利息

四张卡：
- 本周期预计可存
- 银行存款本金
- 预估累计利息
- 日常储蓄余额

不再把“累计储蓄本金”和“当前储蓄总额”并排显示成两个容易混淆的数字。

二、结果页同时显示“预计”和“已确认”
现在显示：
- 收入
- 消费
- 预计储蓄增长
- 已确认储蓄净增

“已确认储蓄净增”继续按真实发生日期统计：
计划储蓄、零花钱转储蓄、周期结余、专项结余、额外储蓄、储蓄取用等都会实时改变。

“预计储蓄增长”在此基础上，再加入当前周期预计会在本月结算的剩余零花钱。

结果明细里同时显示：
- 本月储蓄率
- 本周期预计可存
- 本月已确认储蓄净增

三、专项资金规划增加完整资金变化
每个专项现在直接显示：
- 总预算
- 已备资金
- 已经花掉
- 专项剩余

并显示三段式资金条：
- 已花：暖色
- 剩余可用：绿色
- 尚未备妥：灰色

例如预算 ¥500、已花 ¥100、剩余 ¥400，
资金条会明确显示约 20% 已花、80% 剩余。

四、专项支出明细
专项资金规划中新增可折叠“支出明细”。

每一笔由“记一笔支出 → 专项支出”产生的记录都会自动出现在这里，包括：
- 日期
- 备注
- 总支出金额
- 其中用了多少专项资金
- 如果超支，超出的部分来自零花钱还是储蓄

在专项明细里删除这笔支出，与结果页删除同一条流水完全联动。

五、专项流水可删除
结果页现在为以下专项状态流水补上“删除”：
- 专项结余转储蓄
- 专项归档
- 专项恢复

删除归档记录时，如果有关联的结余转储蓄，会一并撤销并恢复专项，避免只删流水却留下错误余额。

六、零花钱转专项计入已备资金
此前“零花钱转专项”已经影响专项实际可用余额，但“已备资金 / 缺口”没有同步。
本版已修正：
零花钱转专项后，专项的已备资金、资金缺口和进度条都会同步变化。

七、银行转存提醒重新排版
提醒额度输入与保存按钮改为纵向同宽排列，
下方金额、进度条和达标卡保持统一边距和对齐。
