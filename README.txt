SafeSpend PWA V8.7 · 最近流水可修改 + 专项规划暖色版

1. 专项进度条颜色调整

“支出规划”不再使用浅绿色。
现在采用同一暖色系区分：
- 绿色：已备资金，但还没有安排具体用途
- 浅棕：已经规划、尚未实际花掉
- 深棕：已经实际花掉
- 灰色：仍未备到的资金

“支出规划”和“已经花掉”在视觉上属于同一类资金用途状态，
但通过浅棕 / 深棕区分计划与实际。

2. 最近流水增加“修改”

“现在 → 最近流水”中的可编辑真实流水会显示小号灰色“修改”。

支持：
- 普通支出：修改花钱日期、金额、备注
- 专项支出：修改花钱日期、金额、备注；专项归属保持不变
- 固定账单实际支出：修改实际支出日期、金额、备注，账单周期绑定保持不变
- 单次额外收入：修改日期、金额、备注
- 周期收入：修改金额；日期保持锁定，因为日期定义收入周期和生活费覆盖
- 基础生活结算：修改实际基础生活支出
- 额外储蓄：修改日期、金额、备注
- 零花钱转储蓄：修改日期和金额
- 零花钱转专项：修改日期、金额和目标专项

系统生成的状态记录，例如专项归档、专项恢复、专项结算等，不提供直接修改，避免破坏关联链路。

修改后会调用原有记账引擎重新计算零花钱、专项、储蓄和结果统计。

3. 修复专项规划回滚

修正了 V8.6 中“删除由支出规划转换而来的真实专项支出”时，
规划恢复代码位置错误的问题。

现在删除这类真实支出后，
原支出规划会正确恢复到专项中。
