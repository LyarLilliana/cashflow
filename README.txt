SafeSpend PWA V9.2 · 长按管理 + 紧凑流水版

这版主要解决结果页流水“肥、笨、操作按钮难看”的问题。

一、结果页不再显示任何 ⋯ / 修改 / 删除按钮

流水条目恢复为纯信息展示：
- 左侧：流水名称 + 日期 / 项目 / 备注
- 右侧：金额
- 不再额外占一行或一列放操作按钮

需要管理时：
长按任意一条“结果 → 流水记录”约 0.5 秒，
再弹出：
- 修改这条流水
- 删除这条流水

上下滚动超过约 9px 会自动取消长按，
避免滑列表时误触。

同时阻止手机浏览器自己的文字选择 / 长按菜单，
让长按更像 App 内操作。

二、流水排版整体压缩

结果流水和最近流水共用更紧凑的样式：
- 外层流水卡片左右留白减少
- 单条上下间距从 16px 压缩到 11px
- 标题字体稍微缩小
- 备注 / 日期行更紧
- 金额字体和右侧占宽缩小
- 行间分隔仍保留

这样同一屏能看到更多流水，不会再出现每条记录很“厚”的感觉。

三、最近流水

“现在 → 最近流水”仍严格只取当前收入周期，
最多显示最近 8 条。

这里完全没有：
- 长按管理
- 修改
- 删除

它只负责快速查看本周期最近发生的流水。

页面仍只写：
“只显示最近8条”

四、结果流水完整修改逻辑保持

结果页长按后进入“修改”，仍然是 V9.1 的完整编辑逻辑，
不是只改日期。

支出可重新修改：
- 支出来源
- 固定账单 / 专项
- 金额
- 花钱日期
- 专项超支来源
- 备注

收入可重新修改：
- 对应收入计划
- 到账金额
- 下一次周期收入日期
- 优先储蓄
- 单次收入备注
- 专项预留

基础生活、额外储蓄、零花钱转储蓄 / 专项也继续按各自原始输入表单修改。

流水搜索、专项规划、专项进度条及其他现金流逻辑保持不变。
