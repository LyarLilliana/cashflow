SafeSpend PWA V5.4 · 细节完善版

本版调整：

1. 固定账单
“已处理”统一改为“已支付”，与“无需处理”并列。

2. 专项归档资金流水
归档专项时会在流水中明确记录：
- 专项名称
- 已备金额
- 已花金额
- 归档时专项余额
- 归档金额
归档本身不会再次扣款。
恢复专项时也会留下“专项恢复”状态流水。

同时，收入流水若含专项预留，会写出具体专项名称和预留金额。

3. 今日基础生活
当天结算后仍可再次点击编辑。
保存修改会更新原来的结算记录，不会重复创建第二条。

4. 专项周期安排
“周期安排”一行只显示日期。
每周期建议金额仍在上方单独显示。

5. 单次额外收入
“记录收入”中新增明确的“单次额外收入”入口。
选择后无需填写下一次周期收入日期，并可填写备注，例如奖金、退款、临时补贴。
流水会明确显示“单次额外收入 · 备注”。

部署：
将 ZIP 内全部文件覆盖 GitHub 仓库根目录即可。
