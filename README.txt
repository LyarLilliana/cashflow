SafeSpend PWA V5.1 · 专项周期规划模块版

本版重做专项资金缺口提示。

一、专项从“近期必须处理”中独立出来
现在“现在”页顺序为：
- 下一笔周期收入
- 近期必须处理
- 专项资金规划
- 最近流水

只有专项存在资金缺口或专项已经超支时，“专项资金规划”模块才显示。

二、专项建议按未来周期收入具体计算
只使用周期性收入计划：
- 每周
- 每两周
- 每月

一次性额外收入不计入周期规划。

例如：
专项还缺 600 元
截止日前还有 3 次周期收入
则显示：
- 资金缺口 ¥600
- 还剩 3 个周期收入
- 每个周期建议预留 ¥200
- 下一次具体是哪一天、哪项收入、建议预留多少
- 后续周期日期和金额安排

三、异常情况单独提示
- 未设置截止日期：提示先补截止日期
- 截止日已过：提示尽快补足
- 截止日前没有周期收入：提示调整截止日期或从现有资金补足
- 专项余额已经为负：单独显示专项超支

四、记录收入时同步使用周期建议
专项预留输入框会显示：
“缺多少 / 截止前还有几个周期收入 / 本周期建议多少”
默认填写本周期建议预留额。

其他资金逻辑保持不变。
