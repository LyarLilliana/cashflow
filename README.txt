SafeSpend PWA V9.4 · 单次额外收入日期可修改版

本版补齐“结果 → 流水记录 → 长按 → 修改”里的单次额外收入日期。

现在修改“单次额外收入”时，可以重新编辑：
- 到账日期
- 到账金额
- 单次收入备注
- 本次优先储蓄
- 专项预留
- 收入类型 / 对应收入计划

到账日期默认显示原记录日期，
可以改成之前真正收到这笔钱的日期，
但不能改成未来日期。

修改日期后会真实参与联动：
- 结果页会归入新的日期范围
- 流水排序会按新日期变化
- 单次额外收入会重新归属到该日期对应的收入周期
- 零花钱、专项、储蓄和结果统计会重新计算

周期收入日期仍不开放修改，
因为周期收入日期本身就是周期边界，会影响基础生活覆盖、账单预留等整套周期逻辑。

V9.3 的长按提示、长按管理、紧凑流水、流水检索、专项规划等功能保持不变。
