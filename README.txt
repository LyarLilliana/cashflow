SafeSpend PWA V4.9 · 无需处理 + Android 日期修正版

一、固定账单新增“无需处理”
“近期必须处理”中的固定账单现在有两个中性操作：
- 已处理
- 无需处理

“无需处理”的含义：
- 仅关闭当前这个账单周期
- 不产生支出
- 如果这个周期之前已经预留过账单金额，会自动释放该笔预留
- 零花钱和本周期预计可存随之重新计算
- 当前周期关闭后，列表自动切换到下一周期
- 删除“无需处理”流水后，该周期会恢复

二、Android 日期选择修正
此前为了让 iPhone 日期显示成统一的 YYYY-MM-DD，日期控件使用了透明原生 input + 自定义文字层。
部分 Android 浏览器会因此出现日期无法点击、无法填写或日期选择器不弹出的情况。

V4.9 改为：
- iPhone / iPad：继续使用统一 YYYY-MM-DD 的自定义显示
- Android：直接使用系统原生日期输入控件，确保可以点击和选择日期
- 其他平台：同样优先使用原生日期控件

资金计算、固定账单开始周期、表单双栏布局等其他逻辑保持不变。
