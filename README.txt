SafeSpend PWA V10.8 · 基础生活标准按日期生效

1. 计划基础增加“生效开始日期”
- 每日基础生活标准从指定日期开始生效。
- 可以提前设置未来调高或调低的标准。
- 同一个生效日期再次保存会更新该条规则。

2. 基础生活标准改为时间轴
- 历史标准保留。
- 某个日期使用该日期当时已经生效的最新标准。
- 跨调价日期的收入周期按每天对应标准逐日计算，不再把整周期套用一个金额。

3. 相关计算统一联动
- 收入到账时的基础生活预留按日期规则重新计算。
- 今日基础生活剩余预留按当天标准计算。
- 建议每日总可花同步变化。
- 忘记结算的过去日期按该日期当时的计划标准自动补结算。
- 已存在的基础生活结算在规则被回溯修改时，会更新当天预留标准；用户手动填写过的真实消费金额继续保留。
- 当前零花钱、本周期预计可存和结果统计随之重新计算。

4. 规则管理
- 计划页会显示当前标准、下一条未来标准和历史调整记录。
- 点击日期规则可载入修改。
- 删除某条日期规则后，该区间自动沿用上一条规则，直到下一条标准生效。
