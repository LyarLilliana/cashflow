SafeSpend PWA V8.5 · 专项支出规划版

本版为“专项”加入内部支出规划。

适用场景：
例如一个“旅行 ¥3,500”专项中，提前知道：
- 机票 ¥620
- 酒店 ¥600
- 火车票 ¥500
- 音乐剧 ¥300
但这些钱还没有真正支付。

现在每个专项都可以新增“支出规划”：
- 用途
- 预计金额
- 预计花钱日期（可留空，也可以填未来日期）

核心原则：
“计划支出”和“实际支出”分开。

新增支出规划时：
- 不会提前扣掉专项余额
- 不会进入消费统计
- 不会进入流水
- 不会影响储蓄
它只是把专项预算提前分配到具体用途。

专项详情会显示：
- 支出规划有多少项
- 待支出规划合计
- 还未分配用途的预算
- 当前专项资金能否覆盖这些待支出规划
- 如果“已经花掉 + 待支出规划”超过总预算，会明确提醒超出的金额

支出规划支持：
- 添加
- 修改
- 删除
- 记为支出

点击“记为支出”后：
会自动打开现有“记一笔支出”表单，
并自动填好：
- 专项
- 金额
- 用途
- 花钱日期默认今天

用户仍可在真正记账前修改金额、备注、花钱日期和超支来源。

实际保存支出后：
对应支出规划会自动消失，并转为真实专项支出。

如果之后删除这笔由规划转换来的真实支出：
原支出规划会自动恢复，避免计划凭空丢失。

“近期必须处理”也会显示在下一次收入日前需要发生的专项计划支出。

专项还有待支出规划时，不允许直接“结算并归档”，需要先记为支出或删除规划。

旧数据自动兼容：
原有专项会自动补上空的 plannedExpenses 数组，不影响以前的专项、支出和储蓄数据。
