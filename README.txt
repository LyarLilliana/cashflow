SafeSpend PWA V4.8 · 固定账单纳入周期版

新增固定账单“开始纳入”选择：
- 当前周期
- 下个周期

例如今天新增一个每月 68 元的固定账单：
选择“当前周期”，本月对应账单周期立即参与待处理与收入分配。
选择“下个周期”，本月完全跳过，从下个月对应账单周期开始参与计算。

如果一笔账单原本已经在当前周期被预留，随后修改成“下个周期开始”：
- 当前周期会从计算中释放
- 零花钱 / 本周期预计可存会重新计算
- 下个周期再正常进入账单预留

兼容旧数据：
旧版固定账单没有 startMonth 字段时，继续按原有“已经生效”处理。

“近期必须处理”里的“已处理”按钮也改为中性灰色：
- 它只是操作按钮
- 不再使用绿色强调色
- 不承担提醒或警示功能

其他资金逻辑保持不变。
