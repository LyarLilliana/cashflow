SafeSpend PWA V5.6 · 收入储蓄显示 + 账单措辞统一版

本版包含两项调整：

1. 收入流水显示计划储蓄
每一笔收入流水现在都会明确显示：
- 收入日期
- 计划储蓄
- 当时零花钱
- 基础生活
- 如果有专项预留，也继续显示具体专项名称与金额

例如：
2026-09-30 · 计划储蓄 ¥200 · 当时零花钱 ¥90 · 基础生活 ¥210 · 专项 旅行 ¥100

即使计划储蓄为 ¥0，也会明确显示，便于回看每笔收入当时是怎么分配的。

2. “无需处理”统一更名为“无需支付”
固定账单中的按钮、提示、流水状态和撤销提示全部统一使用：
“无需支付”

和“已支付”形成一组更明确的账单状态。

其他资金逻辑保持 V5.5 不变。
