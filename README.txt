SafeSpend PWA V9.9 · 流水校准 Debug 版

本包基于 V9.8 功能继续更新，并按照 2026-10-04 SafeSpend 备份流水完成回归校验。

本次修复：
1. 同一日期内统一资金执行顺序：上一周期结算 → 当日收入建立预算池 → 当日支出消费预算池。9 月 30 日先录固定账单、后录周期收入的情况会按真实资金来源结算。
2. “现在”和“结果 → 当前周期”的预计可存统一采用周期结算口径。零花余额为负时，缺口会同步压低本周期最终可存。
3. 专项资金条改为以“实际已备资金”为现金基数。实际准备金额高于原预算时，新增资金完整进入专项剩余和未规划可用。
4. 补齐 V9.8 当前周期固定账单同步修复。新增、修改、核销固定账单时都会同步当前开放周期的账单预留。
5. 数据键升级至 safespend_cashflow_v70，并自动承接 v69 及更早版本数据。
6. Service Worker 缓存升级为 safespend-v9-9-ledger-debug，便于 Safari/PWA 获取本次代码。
