SafeSpend PWA V7.6 · 当前周期储蓄口径对齐版

本版修正“现在”和“结果 → 当前周期”之间的储蓄口径不一致。

此前：
- 现在页“本周期预计可存”只显示已经确定进入储蓄的钱
- 结果页“预计储蓄增长”会再加上当前剩余零花钱

因此会出现：
现在：¥320
结果当前周期：¥418.74

这不是随机误差，而是：
¥418.74 = ¥320 已进入储蓄 + ¥98.74 当前剩余零花钱

由于两个位置都使用“预计”含义，应该采用同一口径。

V7.6 现在统一为：

本周期预计可存 =
当前周期已进入储蓄
+ 如果周期此刻结束会沉淀的正数剩余零花钱

所以示例中：
¥320 + ¥98.74 = ¥418.74

现在页与结果页当前周期会一一对齐。

同时结果页“预计储蓄增长”下方会直接显示组成：
“已进入储蓄 ¥320 + 预计周期结余 ¥98.74”

现在页“本周期预计可存”下方也会显示：
“已进入储蓄 ¥320 + 当前剩余零花钱 ¥98.74”

注意：
储蓄页顶部“当前储蓄资产”仍只显示已经真正进入储蓄的金额。
因此示例里仍是 ¥320，而不是 ¥418.74。
¥98.74 目前仍是零花钱，只有周期结束后若仍有剩余，才真正转入储蓄资产。

专项支出仍按实际消费统计，但如果使用的是之前已经预留好的专项资金，
不会再次减少当前周期的储蓄，所以“消费 > 本周期收入”并不必然意味着储蓄为负。
