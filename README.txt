SafeSpend PWA V9.8 · 固定账单预留 Debug 版

本版修复一类会让“当前零花钱突然少一笔固定账单”的问题。

复现逻辑：
1. 当前收入周期已经开始。
2. 后来在计划页新增 / 修改一笔固定账单，并选择“当前周期”。
3. 旧版本只把账单计划存进去，却没有把它真正同步进当前收入流水的账单预留。
4. 因此点击“已支付”时，系统判断“没有预留”，又从零花钱扣一次。
5. 用户再去修改另一笔流水时，会觉得那笔固定金额没有恢复。

V9.8 修复：
- 新增固定账单且选择“当前周期”时，立即同步当前开放收入周期的账单预留。
- 修改固定账单金额、扣款日、开始周期时，也同步当前开放周期。
- 点击“已支付”前会再自检一次，避免旧数据漏预留。
- 对旧版本已经产生的“本应从账单预留核销、却从零花钱扣”的当前周期记录，升级后首次打开会自动检查并修复，不需要再手动重录。
- 已结束的历史周期不会被重写。

同时修复固定账单“实际金额高于预留金额”的资金来源：
- 先用账单预留。
- 超出预留的部分从零花钱承担。
- 零花钱不足时再按原逻辑影响储蓄。
这样把实际账单金额从 660 改成 330 时，差额会正确回到零花钱，而不是只在储蓄侧变化。

专项页顺便补齐：
“支出明细 · X 笔 · ¥总支出”
与“支出规划 · X 项 · ¥总规划”保持一致。

其余 V9.7 功能保持不变。
