SafeSpend PWA V10.2 · 账单周期与预计储蓄一致性修复

本版重点修复固定账单在不同缴纳周期之间串用预留的问题。

1. 固定账单预留按“账单 + 缴纳周期”分别核算
- 未来周期提前付款不再消耗当前周期的账单预留。
- 补缴旧周期也不再错误占用当前周期资金。
- 超出对应周期预留的部分才从零花钱承担。

2. 本周期账单支持剩余应付金额
- 固定账单可识别部分付款。
- 本周期待付金额按该周期实际剩余金额计算。

3. 本周期预计可存与零花缺口统一
- 提前支付未来账单、补缴旧账单、账单超出预留的金额都会进入零花缺口。
- “当前零花钱”“本周期预计可存”“本周期资金缺口”使用一致口径。

4. 数据保持原样
- 历史流水的账单周期不做猜测性改写。
- 用户可以继续通过流水修改原始记录。
