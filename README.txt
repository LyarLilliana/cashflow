SafeSpend PWA V4.4 · 日期显示统一版

本版只处理日期输入框的视觉一致性，不改变资金计算。

iPhone Safari 会把原生 date 输入框显示成“2026年9月30日”这种系统格式，
因此它看起来和金额、数字输入框不是同一套风格。

V4.4 改为：
- 页面上统一显示 YYYY-MM-DD
- 例如 2026-09-30
- 字号、字重、左右留白、高度与其他输入框统一
- 仍然保留 iPhone 原生日期选择器
- 点击这个看起来像普通输入框的日期框，依旧会弹出系统日期选择界面
- 手机端继续保持两列分栏
- 空日期显示 YYYY-MM-DD 占位

资金逻辑完全不变。
