莱雅现金流 PWA 测试版

1. 先在电脑或手机浏览器打开 index.html 预览功能。
2. 真正作为 iPhone PWA 安装时，需要把整个文件夹放到 HTTPS 网站上。
3. 在 iPhone 的 Safari 打开部署后的网址，点“分享”→“添加到主屏幕”。
4. 安装后可独立全屏运行，并支持离线使用。
5. 数据保存在当前浏览器 / PWA 的本地存储中。请定期在“设置”里导出 JSON 备份。
6. “分享本月摘要”可直接把月度现金流摘要分享给 ChatGPT。
7. JSON 是完整备份，CSV 是流水表。

当前默认规则：
- 500 元到账：默认存 200 元
- 600 元到账：默认存 300 元
- 每日餐标：30 元
- 月储蓄目标：900 元
- 月固定续费参考：304 元
- 默认到账周期：7 天
- 10 月旅行预算：3500 元
- 10 月课程预算：1400 元
