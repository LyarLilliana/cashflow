SafeSpend PWA V10.10 · 基础生活计划页重排

1. 计划基础改为清晰的状态结构
- 当前标准：显示今天实际生效的每日基础生活标准及其生效日期。
- 新增 / 修改规则：输入生效开始日期和每日标准，统一用于新增或修改。
- 下一条标准：显示最近一条未来生效规则，包括开始日期和金额；点击可直接载入修改。
- 原基础生活标准时间轴从计划页移除。

2. 月度储蓄目标独立成块
- 与基础生活规则分开显示。
- 使用独立“保存月度目标”按钮。

3. 基础生活规则变更进入流水
- 新增、调整、取消规则时会生成一条 living_rate_change 设置记录。
- 流水显示操作日期、生效日期和金额变化。
- 该记录仅用于回看设置历史，不参与收入、支出、余额、储蓄率、预计储蓄等计算。

4. 基础生活计算逻辑保持按日期生效
- 当前规则与未来规则继续按日期逐日参与相关计算。
- 删除规则后按上一条规则自动衔接。
