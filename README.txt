SafeSpend PWA V7.7 · 当前储蓄资产预计口径版

本版把“储蓄 → 现在属于储蓄的资产”改为与“本周期预计可存 / 当前周期预计储蓄增长”一致的预计口径。

现在：
预计日常储蓄 =
已经进入储蓄的余额
+ 当前周期预计会沉淀的剩余零花钱

当前储蓄资产 =
预计日常储蓄
+ 银行存款本金
+ 预估累计利息

例如：
已经进入储蓄 ¥320
当前剩余零花钱 ¥98.74

则：
预计日常储蓄 = ¥418.74

如果没有银行存款和利息：
“现在属于储蓄的资产”也显示 ¥418.74。

页面会同时拆开显示：
- 预计日常储蓄
- 其中已进入储蓄
- 预计周期结余
- 银行存款本金
- 预估累计利息

特别处理：
不能把“预计储蓄增长”整笔再加到实际储蓄余额上，
因为其中已经进入储蓄的部分本来就在实际储蓄余额中，会造成重复计算。
所以这里只补加尚未真正沉淀的“预计周期结余”。

银行转存提醒仍然只使用真正已经进入日常储蓄的可用余额，
不会把尚未沉淀、仍可能被继续消费的零花钱提前当成可转存银行的钱。
