SafeSpend PWA V9.1 · 结果页完整流水编辑版

这版重新定义“最近流水”和“结果流水”的职责。

一、现在 → 最近流水

最近流水现在只显示“当前收入周期”的流水。
最多显示最近 8 条。

这里不再出现“修改 / 删除”功能，
只用于快速查看当前周期刚刚发生了什么。

页面提示仍保持简洁：
只显示最近8条

二、结果 → 流水记录

修改和删除功能只保留在结果页。

为了避免流水右侧堆叠“修改 / 删除”按钮，
每条结果流水现在只显示一个很轻的“⋯”操作按钮。

点击后再出现：
- 修改这条流水
- 删除这条流水

因此流水列表本身更干净。

三、“修改”改为完整还原原始输入

不再只是改日期或金额。

对于可编辑流水，修改界面会尽量还原当时对应的原始输入表单。

收入流水可修改：
- 对应收入计划
- 到账金额
- 下一次周期收入日期（周期收入）
- 本次优先储蓄
- 单次收入备注
- 各专项预留金额

修改后：
基础生活和固定账单会根据新的收入条件重新计算，
零花钱、储蓄和专项余额同步重算。

支出流水可修改：
- 支出来源
- 对应固定账单 / 专项
- 金额
- 花钱日期
- 专项超出部分支付来源
- 备注

因此可以把一笔误记成“零花钱”的支出改成“专项”，
也可以修改专项、金额、日期和备注。

基础生活结算：
- 修改当天实际基础生活支出

额外储蓄：
- 日期
- 金额
- 备注

零花钱转出：
- 转入储蓄 / 专项
- 目标专项
- 金额

四、系统状态流水

通过“已支付”快捷按钮产生的账单核销、
专项归档 / 恢复 / 结算等系统状态流水，
因为没有对应的完整原始输入表单，
不会伪造“修改”功能。

它们在结果页仍可通过“⋯”删除，
由原有联动逻辑负责恢复相关余额或状态。

五、其余功能

结果页流水检索继续保留：
金额 / 项目 / 备注 / 日期 / 流水类别都可搜索。

专项支出规划、进度条、储蓄预计口径、银行转存提醒等 V9.0 功能保持不变。
