SafeSpend PWA V10.1 · 多日基础生活日期联动

本版调整多日基础生活支出的交互与每日预留口径。

1. 多日支出直接占用每日基础生活预留
- 当天分摊金额直接从当天基础生活预留中扣除。
- 结算页顶部直接显示“今日基础生活剩余预留”。
- 例如今日标准 ¥30、买菜分摊 ¥20，页面直接显示今日剩余预留 ¥10。
- 当天另外发生的基础生活支出继续从这笔剩余预留中扣除。

2. 日期与覆盖天数三向联动
- 移除单独的“付款日期”字段。
- “开始日期”同时作为实际付款日期和分摊开始日期。
- 输入覆盖天数后自动计算结束日期。
- 修改开始日期时，按当前覆盖天数自动更新结束日期。
- 修改结束日期时，自动反算覆盖天数。
- 开始日期、结束日期、覆盖天数都可自行编辑。

3. 数据兼容
- 旧版多日基础生活记录会自动补齐结束日期。
- 数据键升级为 safespend_cashflow_v72。
